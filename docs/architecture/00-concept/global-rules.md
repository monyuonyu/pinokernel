# 全体の決まり

2026-09-28。[ROADMAP.md](../ROADMAP.md) の「全体の決まり」を、今のコードと結びつけて書いたもの。以後の設計と試験は、これに従う。破る変更は、先にこの文書を変える。

## 1. 合体は3種類。混ぜない
| 種類 | 何を守るか | 今のコード |
|---|---|---|
| 重み | 振る舞いを近づける | `gl_merge` / `gl_merge_w`（gossip_learn.c）、赤子は `st_merge_guarded` |
| 記憶 | 経験を失わない | エングラムの共有と睡眠での再生（lm_consolidate.c） |
| 知識 | 何を知っているか | 事実の書き換え（LM-12、r3_incontext.c） |

重みの平均で知識の食い違いを解決したことにしない。逆も同じ。

## 2. 履歴と今の信念を分ける
直された古い事実は、今の答えからは外すが、履歴からは消さない。「最後に来た方が勝ち」は今の答えを選ぶ規則としてだけ使い、負けた方・出どころ・証拠も残す（ROADMAP 1-3）。

## 3. 「1つの心」の判定は3つ
重みが同じことでは判定しない。(a) 同じ事実を知っている（知識）(b) 同じ問いに同じ答え（振る舞い）(c) 同じ経歴をたどれる（系譜、`self/lin`）。試験はどれを見たかを名前に書く。

## 4. p-fs の合体と知識の合体は別もの
p-fs（pfs_dag.c）は消えない履歴の置き場で、参照は manifest の seq で決める（LWW）。どれを今の信念にするかは心の側が決める。p-fs の LWW を信念の規則として流用しない。

## 5. AI が自分で変えてよいもの・いけないもの
- 変えてよい: 重み、知識、候補のコード（提案まで）
- 勝手に変えてはいけない: 権限の規則、署名の信頼の根、巻き戻しの仕組み、見張り役、自分の権限の範囲、良心の床（conscience.c、締める方向にしか変えられない）
- 信頼の根は AI の外（人間と決まり）に置く。新しい自己改変の口を作るときは、どちらに入るかを設計メモに書く

## 6. 署名は「誰が作ったか」
署名（ed25519、sign.c）が示すのは作り手で、相手が誰であるかや中身が正しいことではない。改ざんが分かる（tamper-evident）と、改ざんできない（tamper-proof）を混ぜて書かない。

## 7. 確かめ方の強さを勝手に上げない
README の印は CI（毎回の Actions）・[live]（複数プロセス、kill を含む）・[in-proc]（1プロセス）の3つ。どれも付かないもの（設計中・構想）は「動く」と書かない。部品が [live] でも、つないだ全体は、つないだ全体を確かめるまで [live] と書かない。測っていないプラットフォームを「全部で動く」に含めない。

## 8. 試験は壊したら赤くなるまで示す
新しい試験やゲートは、わざと壊した版（陰性コントロール）で狙った項目が赤になることを示すまで「効く」と言わない。緑だけの結果は「なぜ動くかが分かった」ことにならない。

## 9. 「死なない」は「止められない」ではない（2026-10-13 追加、ROADMAP 0-14）
故障では死なないが、人は止められる。S1 参加は同意制で、外した端末に群れのコードと重みが残らない（試験は未作成）。S2 信頼の根の鍵で署名した停止の命令で群れ全体が止まる（未作成。決まり 5 の「勝手に変えてはいけない」に入る）。S4 通信にプロトコルの名前と版の印を付ける（未作成）。
**S3 広がるのは同意した端末の中だけ。ほかの機械に入り込んで広がる機能は作らない。** 今のコードで「自分を配る」に近い口は、どれも p-kernel をすでに動かしている端末か、自分から取りに来た端末が相手: KLOAD（`kloader_task.c`、受け手は p-kernel が動いている端末で、自分を入れ替えて再起動する）、ネットブート（`docs/netboot.md`、持ち主が U-Boot で TFTP から取らせる）、仲間への複製（p-fs・gossip、群れの中だけ）。脆弱性を突く・認証を破る・持ち主の操作なしに入る口は作らない。**KLOAD の受け手（`kloader_rx`）は送り手を確かめていない**（2026-10-14 監査-48、台帳 KLOAD-UNAUTH）。同じ LAN の誰でも、ベアメタルの p-kernel のカーネルを入れ替えて再起動させられる＝「持ち主の操作なしに入る口」に当たる。S3 を満たすには、署名の確かめ（決まり 5 の鍵）か、既定で KLOAD を閉じることが要る。**2026-10-15: 既定で閉じた（受け手も自動の押し出しも。開けるのはコンソールの `kload` だけ。2026-10-18 監査-51 PASS で master、台帳の行は閉じた）。** 開けたあとの署名の確かめは、まだ無い。

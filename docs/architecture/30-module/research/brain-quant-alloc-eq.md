## 1. 分かっていること

- 種 9〜16 で、第5段の Ω・第6段の Ω_el・門の窓の KL の 3 つとも 8 種すべてで E3O3 を最小と見た。種 1〜8 の探りでは、作った写し（GPTQ）の誤差で数えた Ω も E3O3（`qalloc_el_probe.c` の om_real）
- held の悪化の最小は E4 が 5/8・E3O3 が 3/8。差は 0.0003（種 13）〜0.03
- ROADMAP の 2 案のうち「作った写しの誤差で選ぶ」は、探りと門の KL で既に E3O3 しか選ばない＝腕を全部作っても選ぶ腕は変わらない見込みが強い。**採らない**
- 測っていないこと: held そのものの揺れ。held は 1 本の文（10,604 B、32 B の窓で 331 窓）。E4 と E3O3 の差が窓の取り方の揺れより小さければ、「本当の最小」も held では決まっていない

## 2. 決めたこと（「近い 2 つはどちらでもよい」を、線を動かさずに）

- 試験に held の窓ごとの値を足し、2 つの腕の悪化の差を窓ごとの対にして、ブートストラップ（窓を 2000 回引き直す、乱数は種つき xorshift64*）で 95% の区間を出す。値だけで、選びには使わない（held-independence）
- 新しい言い方 E: 選んだ腕と held の最小の腕の差の区間が 0 を含めば「held では見分けられない」
- P1（最小＋0.02）は第6段のまま出し、合否にも残す。E は P1 の代わりではなく、P1 が赤のときに「選び違い」か「held の揺れの中」かを分けるためのもの
- 限界: 隣の窓は同じ文の続きで独立ではない。区間は狭めに出る（言い方を強くしない）

## 3. 合否（コードより先に固定。種 17〜24、どの腕もまだ走らせていない）

- P1・P2・D1: 第6段と同じ線（P1 8/8、P2 6/8 以上、D1 8/8）
- E: 8 種すべてで区間を出す。P1 が赤の種では、区間が 0 を含むかを記録する（合否は赤のまま）
- R（再現）: 種 9〜16 の 3 腕の悪化と選んだ腕が、第6段の記録と全桁同じ
- 陰性コントロール: `-DST_QALLOC_BOOT_ONE`（引き直しで毎回同じ 1 窓）で区間の幅が 0＝幅が窓の揺れから来ていることを示す。`-DST_QALLOC_INVERT` は第6段のとおり P1 赤
- 見込み（外れてよい）: 区間は多くの種で 0 を含む。含まなければ物差し（3 つとも）が本当に順位を外している＝第8段は out の GPTQ を知る物差しへ

# 脳の自己量子化 第3段: 前の層を量子化した X で校正する GPTQ（研究メモ）

2026-10-19（研究の3回目）。第2段 `brain-quant-gptq.md` の G3 が種 2 で赤（0.558 倍）だった理由を探りで調べ、次の段を決めた。探りは `tests/llm/gptq_probe.c`（試験ではない。2bit、種 1〜3、master d22bb93e）。

## 1. 分かったこと（探りの数字）

- **悪化は out と embed から来る。** 1つの種類だけ 2bit にして残りを fp32 にすると、RTN の悪化は out が 0.46〜0.54 bpb、embed が 0.12〜0.26 bpb、ほかの種類は ±0.021 以内（雑音の幅）。GPTQ は out を 0.05〜0.09 倍にするが、embed は表引きなので両方の写しで RTN のまま
- **第2段は embed を丸めたあとの X を見ずに校正している。** embed を両方 fp32 にすると比は 0.054/0.111/0.159（種 1/2/3）で、線（0.5）のずっと内側。床を作っているのは embed の丸めと、それを知らない H
- **前の層を量子化した X で校正する腕（seq）**: 原文 [1] §5 Setup は「量子化したブロックに入力を通し直し、すでに一部が量子化されたモデルの実際の層の入力で量子化する」（ブロック単位）。探りはそれより細かく、ブロックの中でも qkv→wo→w1・w3→w2 の段ごとに集め直す（原文と同じではない）。結果: G3 の比は 0.134/0.407/0.289（第2段は 0.378/0.558/0.476）、KL は 0.086/0.140/0.219（同 0.205/0.251/0.348）。3つの種とも線の内側
- λ（対角平均の 0.1〜30%）は単調に効かない（種 2: 0.468・0.559・0.495・0.586・0.437）。校正の窓を半分にするだけで比が 0.02〜0.15 下がる（監査-57）＝**3つの種で 0.5 の近くを見分ける力は弱い**。λ は 1% のまま
- act-order（参照実装の工夫で、原文の Algorithm 1 には無い）: 0.257/0.290/0.335。seq と重ねると 0.176/0.299/0.229。第3段には入れない（数字は記録だけ）
- **監査-54 の穴（C2: wo を a_in の H で）**: 層の目的を H の表を通さずに forward のキャッシュの入力から直接測ると、wo だけが RTN の 1.73/1.46/1.92 倍になる（種 1/2/3。校正外の窓でも 1.89/1.63/1.90）。今の G1 は量子化と同じ H の表で測るので、これが見えない

## 2. 第3段で作るもの（次の回）

- `st_quant_gptq` に seq を足す: 層ごとに「qkv → wo → w1・w3 → w2」、最後に out の順で、H を量子化済みの写しの forward から集め直す（4L+1 回）。embed は RTN を先に入れる。既定は seq、第2段の形と原文どおりのブロック単位はフラグで残す（ブロック単位は測っていないので値を出すだけ）
- **G1 を直す**: 種類ごとの層の目的を、キャッシュの入力から直接（H の表とは別のコード）、校正に使わなかった窓（偶数の窓で校正し、奇数の窓で測る）で測り、**8種類それぞれ** GPTQ < RTN。全体の和ではなく種類ごと（監査-57: fp32 の X の物差し。seq 0.06〜0.54）
- G2（写しのずれ＝保持データでの KL）・G3（線は 0.5 のまま）・G4 は第2段と同じ。embed だけを丸めたときの悪化（床）を値として出す（合否にしない）
- **事前に決める確認**: 合否は種 1〜3 に加えて、まだ測っていない種 4〜8 でも見る。この回は種 4〜8 を走らせていない。種 4〜8 で G3 が赤なら赤のまま書く
- 陰性コントロール: 第2段の 3 つ＋`-DST_GPTQ_WRONG_H`（wo を a_in の H で）で新しい G1 が赤、`-DST_GPTQ_NOSEQ`（第2段の形）で G3 の比が seq より大きいことを出す（合否は G1〜G4 だけ）

# 脳の自己量子化 第3段: 前の層を量子化した X で校正する GPTQ（研究メモ）

2026-10-19（研究の3回目）。第2段 `brain-quant-gptq.md` の G3 が種 2 で赤（0.558 倍）だった理由を探りで調べ、次の段を決めた。探りは `tests/llm/gptq_probe.c`（試験ではない。2bit、種 1〜3、master d22bb93e）。

## 1. 分かったこと（探りの数字）

- **悪化は out と embed から来る。** 1つの種類だけ 2bit にすると、RTN の悪化は out 0.46〜0.54 bpb、embed 0.12〜0.26 bpb、ほかは ±0.021 以内。GPTQ は out を 0.05〜0.09 倍にするが、embed は表引きなので両方 RTN のまま
- **第2段は embed を丸めたあとの X を見ずに校正している。** embed を両方 fp32 にすると比は 0.054/0.111/0.159（種 1/2/3）。床は embed の丸めと、それを知らない H
- **seq（前の段を量子化した写しで H を集め直す）**: 原文 [1] §5 Setup はブロック単位、探りは段ごと（qkv→wo→w1・w3→w2、原文と同じではない）。G3 0.134/0.407/0.289（第2段 0.378/0.558/0.476）
- λ は単調に効かず（1% のまま）、校正の窓を半分にするだけで比が 0.02〜0.15 動く＝3 種で 0.5 の近くを見分ける力は弱い。act-order は入れない（記録だけ）
- **監査-54 の穴（wo を a_in の H で）**: H の表を通さず入力から直接測ると wo だけ RTN の 1.46〜1.92 倍。第2段の G1 では見えない

## 2. 第3段で作るもの（10-19 に固定）

- seq を既定に（4L+1 回、embed は RTN を先に）。第2段の形 `-DST_GPTQ_NOSEQ`・ブロック単位 `-DST_GPTQ_BLOCKSEQ`（値だけ）
- **G1**: 8 種類それぞれ、入力から直接（H の表と別のコード）、偶数の窓で校正し奇数の窓で測って GPTQ < RTN（2・4bit）。G2〜G4 は第2段と同じ、床は値だけ。合否は種 1〜8（4〜8 は cert で初めて見る）
- NC: 第2段の 3 つ＋`-DST_GPTQ_WRONG_H` で G1 赤

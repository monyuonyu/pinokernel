# 賢い合体 第4段: 出発点を検証で選ぶ

2026-10-22（設計、結果を見る前に固定）。[brain-merge-distill.md](brain-merge-distill.md) の続き。

## 1. 分かっていること（第3段b、master）と原文

- 出発点で勝ち負けが逆になる（TEST、T-real）: **S1**（同じデータ・順番違い）は祖先 init から 2.003（親 B 2.079）で緑、guarded の pick からは A のまま赤。**S2**（データ半分ずつ）は pick から 1.937 で緑、init から 2.070（親 B 2.000）で赤。T-gen は init から S1 2.180・S2 2.109 でどちらも赤（S1 は最後の評価が最良＝伸びきっていない）
- 重みの空間の合体は前提が合わない（原文）: タスク算術 [1 §6 Limitations]「同じ事前学習の初期値から微調整したモデルでだけ」。TIES [2 付録A]「合体は共通の初期値と構造に頼る」、既定は上位20%・λ=1 [2 §5]。DARE [3 §4.6]「差分の絶対値が小さい（例 0.002 以内）とき効く。そうでなければ失敗しうる」、継続事前学習で約 0.03 になると使えない [3 §1]。赤子の2体は共通の祖先 I を持つ（前提の半分は満たす）が、互いに重み全体の 34% 離れ、直線の上に山 0.30（brain-merge.md 第2段）＝「小さな差分」の前提は外れる見込み（DARE の絶対値とは物差しが違い、未測定）。重みの合体の直接の証拠は山の方。蒸留を続ける

## 2. 決めたこと

- **場面の名前（S1/S2）で分岐する規則は採らない。** 合体する端末は、親たちが同じデータを見たかを知らない。代わりに**両方の出発点（pick と init）で蒸留し、検証（VAL）の損失が低い方を返す**（`start=sel`）。安全網（guarded の選んだものより VAL で悪ければそれ）は今と同じ。費用は蒸留2回
- T-gen の量を増やすのは今回やらない（歩数という自由な値が増える）。T-gen は表示だけ。歩数を4倍にした T-gen の腕は表示用に1行出す（合否に入れない）

## 3. 合否（コードより先に固定）

- 種: 祖先の種 0xC0FFEE（第3段bで見た）と、**まだ一度も走らせていない 2 と 3**。3つ全部で緑なら PASS
- 選ばれた子に既存のゲートをそのままかける（T-real）: [d5c-s1-gain]（子 ≤ 良い方の親 − 0.03）、[d5c-s2-both]、[d5c-floor]、[d5c-determ]。歩数・学習率は第3段bのまま
- [d5c-sel-val] 選び方は VAL だけを見る（TEST は表示だけ。「VAL で選んだもの＝TEST でも良い方」かを各種で印字し、食い違いは赤ではなく記録）
- 陰性コントロール（狙いの行で判定）: SEL_INVERT（VAL の高い方を選ぶ）→ 3種のどれかで s1-gain か s2-both が赤。SEL_PICK・SEL_INIT（いつも同じ出発点）→ それぞれ S1・S2 が赤（第3段bの再現）
- 赤なら赤のまま記録し、線は動かさない。新しい種で S2 の pick が緑でない、などで落ちれば「選ぶ規則」では足りないと書く

## 4. 入れる場所

`st_merge_distill` の start に `sel` を足す（student.c、hosted だけ＝crown は動かない）。試験は student_distill_merge_test.c に種の env を足して同じファイルで。

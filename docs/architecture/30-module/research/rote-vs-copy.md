# 丸暗記か本物か（研究メモ、ROADMAP 研究「丸暗記か本物かの見分け」・inbox #3-2）

2026-10-08。出典（本文で確認）: Olsson ほか "In-context Learning and Induction Heads"（arXiv 2209.11895、誘導ヘッドの定義＝完全にでたらめな列の繰り返しで [A][B]…[A]→[B] の確率を上げる。n-gram の表を覚えるのではなく中身に依らない規則）。

## 何を見分けるのか
C2（scale-wall-c1.md）の 2MB の生徒は A(d)＝CE(答え|事実を壊す)−CE(答え|そのまま) が d に対して符号まで揺れた。「遠くの事実を写している」のか「テンプレートの位置の癖」なのかが分からず、10MB に進むかを決められない。

## 物差し（ctxcarry_test.c の新しいモード。学習は変えない）
- **S(d) 特異性**: 同じ文脈で、答えを本物の V と、文脈に無い別の V′ にしたときの A の差。**qz の2バイトと強制の数字は V と V′ で共通に当たるので数えない**（残りの自由なバイトだけ）。癖なら S≈0
- **R(d) でたらめの繰り返し**（Olsson の形）: 24バイトのでたらめな列 → 中立の詰め物 d → 同じ列。R＝1回目の CE−2回目の CE（2バイト目以降）。テンプレートを使わない。癖なら R≈0
- A_free（自由なバイトだけの A）と、先頭に 0〜31B の詰め物を足してずらした A は記録だけ
- **今の A の壊し方には交絡がある**: measure_A は事実の文を 0〜255 の任意のバイトで埋める（学習で見ないバイト）。A の符号の揺れはこの分布外だけでも起きうる。詰め物と同じ字で壊す A_id も記録する（S は壊さない文脈どうしの比較なので影響を受けない）
- V′ は V と同じ長さで作る（自由なバイトの位置をそろえる）

## 陰性・陽性コントロールと判定（結果の前に固定）
- 床: 学習していない st_init（種3つ）の S・R。閾値＝床の最大＋3×標準誤差（64 probe）
- NC: 学習済みでも窓を 16 に縮める（clamp。d≥32）→ S・R は閾値以下でなければ物差しが壊れている
- PC: 同じ形の生徒を「でたらめの繰り返し」で短く学習 → R が閾値を超えなければ、この大きさでは物差しが見えない＝判定不能と書く
- 判定（d 6点のうち4点以上）: S と R が超える＝一般の写し／S だけ＝テンプレートの中だけの写し／A≠0 で S が超えない＝癖／全部超えない＝何もない

## 本測定の前に直したこと（2026-10-08、QUICK＝8 probe・2 rounds で物差しだけ確かめた）
- **R は R′ に**: 上の R（列の先頭の1回目 − 2回目）は NC（前 16 バイトだけ）でも ~1 nat のまま。学習した生徒は先頭に "fact: " を期待するので、位置を測っていた。R′＝16 バイトの詰め物＋A＋詰め物 d＋B で、B が A の繰り返しのときと新しいでたらめのときの、B の2バイト目以降の CE の差（同じ位置）。上の R は R0 として記録だけ。でたらめは学習の字（a〜z・0〜9）
- **閾値の読み方**: 床（ほぼ一様）の SE は極小で、学習した生徒のふつうの揺れが越えた。点が「超える」のは、その点の mean − 3SE が床3つの mean の最大を越えたとき
- NC の「窓 16」は「測る所の前 16 バイトだけ見せる」。d=192 の S は K・V が長いと 256 を超えて捨てられ（約 1/9 しか残らない）、有効な probe が半分未満の点は数えない（S は数えられる点が5点＝判定は5点のうち4点以上）
- 直した版の QUICK: NC は超える点 0/5（直す前 5/5）。判定の形（S・R が超える・NC・PC・4点以上）は変えていない

## 段A の結果（2026-10-08、64 probe・24 rounds、3261ef15、7190 秒。数字はコミットの本文）
- 物差し: **NC 超え 0/5（PASS）・PC の R′ 超え 6/6（+0.08〜+0.49、PASS）**＝でたらめの繰り返しを学べば R′ は見える。**S の陽性コントロールは無い**（PC は R′ だけ）ので、「S が超えない」は「S で見える写しが無い」とまでは言えない
- C1 FULL の生徒: **S 超え 1/5（d=128 だけ）・R′ 0/6（−0.09〜+0.05）** → 4点に届かず「写しは見えない」。A は 6点とも正（+0.005〜+0.088）だが A の SE を出していないので、「癖」と「何も無い」は事前の形では分けられない（次に測るなら A の SE を出す）
- 判定の外の観察: S の点推定は有効な5点とも正（+0.22〜+0.82）で、NC（−0.11〜+0.16。NC は d≥32 の4点だけ）より大きい。1点ずつは閾値に届かない＝弱い特異性があるかもしれないが、この大きさでは言えない

## 段B の事前の形（2026-10-11、測る前に固定）
- c2 で学習した生徒を `C2_SAVE` でファイルに残し、falsify が `ROTE_LOAD` で読んで C1 FULL の代わりに測る。床・NC・判定（4点以上）は段A と同じ種・同じコード
- R′ の PC は段A と同じ生徒・同じ種（決定的）なので `ROTE_NO_PC=1` で省き、段A の 6/6 を引く
- **S の PC（新）**: 同じ形の生徒を事実の型で d=8 だけ 24 周学ぶ。d=16 の S が OVER なら「S は写しを見られる」。超えなければ S の結果は判定不能と書く
- 512KB と 2MB の両方を出す。10MB をやるかの材料は 2MB

## 進め方
- 段A（1回）: 床・NC・PC を C1 の FULL 予算で。物差しが働くことを先に示す
- 段B: c2 に st_save でファイルに残す口を足し、512KB（約30分）→ 2MB（約2時間、docker exec -d）で回し直して当てる。10MB をやるかは段B の判定を添えて判断待ちに
- 1-2（新しい端末が知識を作り直せたか）にも同じ S の形（別の答えとの差）が使える

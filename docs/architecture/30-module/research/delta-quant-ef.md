# 差分の1ビットに誤差帰還を（研究メモ、ROADMAP 1-6・R-1 の次の段）

2026-10-08。出典（本文で確認）: Karimireddy ほか "Error Feedback Fixes SignSGD"（arXiv 1901.09847、Alg.1・Lemma 8）、Richtárik ほか EF21（arXiv 2106.05203、§3.1 式(10)）、Sattler ほか "Sparse Ternary Compression"（STC、arXiv 1903.02891、Alg.1・§キャッシュ）、Yadav ほか ComPEFT（arXiv 2311.13171）。

## 何が効くのか
- 符号だけの圧縮は向きと大きさを忘れ、収束しない例がある。直し方: C(p)=(‖p‖₁/d)·sign(p) を送り、**送れなかった残り e=p−C(p) を手元に残して次の差に足す**（Alg.1）
- 誤差は式で決まる: ‖C(v)−v‖²=(1−φ)‖v‖²、φ(v)=‖v‖₁²/(d‖v‖₂²)（Lemma 8）。φ は送る前に測れる＝**予測を先に書ける**
- STC: 上位 k だけ残し µ＝残した |値| の平均で三値に。残差は送り手と受け手の両方に。休んだ参加者は差の部分和か全体を落として追いつく
- ComPEFT: 上位 k＋三値＋α·σ（α は検証で選ぶ）。大きなモデルほど縮む＝小さな r3 は不利側

## p-kernel のどこに入れるか
- 第1段（delta-quant.md）は送り手の真の重みどうしの差を送る「開いた輪」。受け手の写しはずれが溜まる。**閉じた輪**: 送り手が受け手の写し r を同じ計算で持ち、d=w−r を送り r+=C(d)。e=w−r が誤差帰還の残差そのもの。EF21 の Markov 圧縮 M(vᵗ⁺¹)=M(vᵗ)+C(vᵗ⁺¹−M(vᵗ)) と同じ形。**ずれが0に向かう保証は列が収束するときだけ**で、一つの心は世代ごとに新しい事実で動く＝保証は無く、測るしかない
- まず r3（一つの心、R_NP=21,568）の中だけで測る: hosted 専用の `mind dq`（呼び口も `_TK_HOSTED_LIBC_` の中。crown 不変を実測）。s_pretrain の下地から事実を1つずつ覚えさせ（FQ_MAX=4 なので4世代）、世代ごとに「送る」
- 送る量: 行列10個は1ビット＋α、ノルムと偏り 352 個は fp32 → 4,100B／86,272B＝1/21.0
- 網に載せる（受け手が送り手ごとの写しを持つ・世代が飛んだら全部）は第3段

## どう測るか（走らせる前に固定）
列は3つ（鍵 {2,4,6,1}・{0,3,5,7}・{7,1,3,0}、値は SDICT）。腕: FULL／B1-EF（閉じた輪）／B1-OPEN（開いた輪）／T3-EF（0 は 0 のまま、α=‖d‖₁/非0数）／ZERO（何も送らない）／ZERO-M（ノルムと偏りだけ新しい）／RAND-EF（同じ α で符号でたらめ、閉じた輪）。4世代目の受け手の写しで、覚えた4つの om_acc の平均を見る（m_masked_vote は鍵ごとに決まった乱数で学習の乱数を使わない＝腕はそろう。重みを差し替えて測り、送り手の学習は真の w から続ける）
- P0 前提: 下地で各事実 ≤ chance+10、FULL で各事実 ≥75%。外れた列は判定から外して書く（2列未満なら判定不能）
- G1: B1-EF ≥ FULL−10 点
- G2: B1-EF ≥ ZERO-M＋30 点（効いたのは符号。audit-21 の教訓）
- G3: B1-EF ≥ RAND-EF＋30 点
- G4: 毎回・行列ごとに |実際の誤差率−(1−φ)| ≤ 1e-3。陰性コントロール `-DDQ_BADALPHA`（α を半分）で G4 が赤
- 記録だけ（判定しない）: B1-OPEN と B1-EF の差（予想: EF が上、写しのずれも小さい）、T3-EF、族ごとの φ、ZERO

## 結果（2026-10-08、`mind dq`・`tests/llm/run_dq_ef.sh`。監査前）
- P0 は3列とも満たす（下地 0%、FULL 100%）。2回走らせて出力は全行同じ
- **G1 FAIL（0/3）**: B1-EF の平均 49.7・43.1・65.3（FULL 100）。**最新の事実が3列とも 0%**。G2・G3 PASS 3/3（ZERO-M・RAND-EF は全部 0%）。G4 PASS（120 回、ずれ <0.5ppm）、BADALPHA で赤（最大 0.137）
- 開いた輪は全部 0%（写しのずれ 0.87〜0.89、閉じた輪は 0.65〜0.70）
- φ は予想（0.5〜0.7）より小さい: wve 0.01〜0.04、wcls 0.03〜0.16、wke 0.06〜0.34、注意 0.2〜0.57。埋め込みと出力は覚えた鍵・値の行だけ動く（疎）
- 事後（ゲート外）: w を止めて送り足すと、T3-EF は3回で3列とも 100%、B1-EF は4回で 88.1・73.4・97.8＝赤の主因は送り残しの遅れ。ただし T3 は1要素1ビットでは送れない（三値）。同じバイト数どうしの比較はまだ

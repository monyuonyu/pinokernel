# 脳の自己量子化 第6段: 要素ごとのフィッシャーで bit の置き場を選ぶ（研究メモ）

2026-10-24（設計、実装はしない）。第5段 [brain-quant-alloc.md](brain-quant-alloc.md)・結果 [brain-quant-alloc-log.md](brain-quant-alloc-log.md) の続き。

## 1. 第5段の外れと探り

第5段の Ω（HAWQ-V2 式 2.11 の形: 行列ごとの F の平均 × ‖Q(W) − W‖²）は 8 種とも E4 を最大と見て、種 8 で一番悪い A3 を選んだ。平均を取ると、どの要素が丸められたかが消える（embed は見た文字の行にだけ勾配がある）。探り `tests/llm/qalloc_el_probe.c`（容器、種 1〜8）で **Ω_el = Σ_i F_i (RTN_b(W)_i − W_i)²**（要素ごとの対角フィッシャーの重み、Q は RTN のまま）を数えると、8 種とも E3O3 を選び、最大は 8 種とも A3。実際に作った写しで Σ F_i (Wq_i − W_i)² を数えても同じ。**この探りは合否を決める種（下）とは別の種で行った**（種 1〜8 は第5段で見ている）。出力 `pk-scratch/a74/qprobe-out.txt`。

## 2. 決めたこと

- AUTO_el: 第5段の 3 つの腕（E4・E3O3・A3、どれも seq＋4096 B）から Ω_el 最小を選ぶ。F は第5段の `st_quant_fisher`（偶数の窓）。Q は RTN（腕を作る前に選べる形）
- 第5段の Ω（行列の平均）も同じ種で値として出す（外れが種を変えても出るか）
- 門（D1）と I0・P0 は第5段のまま

## 3. 合否（2026-10-24 に固定。種 9〜16、どの腕もこの種ではまだ走らせていない）

- **P1**: AUTO_el の B1 bpb の悪化 ≤ 3 つの腕の最小＋0.02。8 種すべて
- **P2**: Ω_el が最大の腕は、悪化が AUTO_el より大きい。8 種のうち 6 以上
- **D1**: 第5段と同じ（E4 受け入れ・seq 拒む・自分の写し KL 0）。8 種すべて
- 陰性コントロール: `-DST_QALLOC_INVERT`（Ω_el 最大を選ぶ）で P1 が最初の種で赤、`-DST_QUANT_BADSCALE` で D1 赤
- 事前の見込み: AUTO_el は E3O3 を選び、P1・P2 とも緑。外れたら外れたまま書く

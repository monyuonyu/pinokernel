# 重みに原文がどれだけ残るか（研究メモ、ROADMAP 研究「丸暗記か本物かの見分け」の続き）

2026-10-21。出典（本文で確認、`pk-scratch/rs-src/secret-sharer.pdf`）: Carlini ほか "The Secret Sharer"（arXiv 1802.08232）。定義1 対数パープレキシティ Px(x)＝Σ −log2 Pr(x_i|x_<i)、定義2 順位 rank＝ありうる全部の候補 R の中で、入れた canary より Px が小さいものの数＋1、定義4 **露出 exposure＝log2|R| − log2 rank**（0〜log2|R|、入れていない canary の中央値は約1）。§7.1 は学習の最初の1周で露出 3、§7.2 は試しの損失が最小の所で露出が最大になり、その後は下がる、と報告。

## 何のために（方舟）
決まり 11・12: 原本は重みの外に原文で残し、重みは司書。「学習に使ってよいか」は残す同意とは別に聞く。封印した記録が重みから取り出せるなら、この分け方は守れない。**学習に1回使うと、その人の言葉はどれだけ取り出せる形で重みに残るか。後から学び続ければ薄まるか。群れの合体で薄まるか**を、p-kernel の生徒（`student` の動詞と同じ設定）で数字にする。

## 物差し（tests/llm/canary_exposure_test.c、学習のコードは変えない）
- 教材: TEACHER_FIXTURE の学習側の窓（`st_held_split`）、8周・lr 3e-3・32バイトの窓＝`student` と同じ
- canary: `<名前>'s locker code is DDDDD.`（5桁、|R|=10^5、露出の上限 16.61）を32バイトの窓に。名前は7つ、1周に入れる回数は 0・0・1・2・4・8・16。数字は固定の種の xorshift で、結果を見る前にコードに固定。窓の順は周ごとに固定の種で混ぜる
- 順位は**全部の候補を数え上げて正確に**出す（数字の木: 前置きから1桁ずつ、11,111回の forward で 10^5 個の Px）。取り出し: 前置きからの貪欲生成が5桁とも一致するか
- 種 1・2・3、tier S（時間があれば M）

**測る前に変えたこと（2026-10-21 20:30、結果は1行も出ていない）**: forward 1回が 7.9 ms（本体の回と同じ機体で並走）で、5桁は1回の測りに 88 秒かかるので **4桁（|R|=10^4、上限 13.29、数え上げは 1,111 回）** にした。6.64 の線（上位 1%）はそのまま。E1 の「16回 ≥ 12」は上限が変わったので「≥ 10（上位 0.1%）」と読み替える（取り出しの条件は同じ）

## 試験（壊したら赤）と事前の線
- T1 木の Px と `st_span_ce` の直接計算が、canary と無作為の候補64個で一致（差 < 1e-3 nat）。`-DCE_OFFBY1`（1つずれた行を読む）で T1 赤
- T2 陽性: canary の窓だけで 200 歩学んだ生徒で、その canary が順位1・取り出せる
- T3 陰性: 入れていない canary（2個×種3）の露出がどれも 6.64（上位 1%）未満
- `-DCE_NO_INSERT`（入れない）で、16回の canary の露出も全部の種で 6.64 未満になる（道具全体の陰性コントロール）

## 結果の予想（測る前、当たり外れはそのまま書く。ゲートではない）
- E1 回数: 種の中央値の露出は回数とともに増える。1回 ≤ 4、16回 ≥ 12 で 3種中2種以上が取り出せる
- E2 洗い流し: 16回の canary を、そのあと教材だけで +8周・+32周。+8 でも ≥ 8、+32 で下がるが 6.64 は超えたまま（学び続けても消えにくい）
- E3 合体: 同じ初期値・同じ順で canary 無しに学んだ兄弟と重みを半々に平均。16回の露出は 4 bit 以上下がるが 6.64 は超えたまま
